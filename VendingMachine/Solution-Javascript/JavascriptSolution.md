# Javascript Solution

For this solution I've decided to do a command line app. As opposed to the Java solution, which is more based on flexing my object oriented skills (designing objects/enums/types) with a typeless language
I'm going to focus on testability and speed. The goal for this was to build something I can visually demo to myself as I write it.

## Results 

I'm more of a typescript person so I did this one quick and dirty and had to learn a lot. If I did this one again I would probably get more familiar with some of the tooling for CLI apps as well as 
look into some better plugins for the IDE to feel more comfortable with the workflow (I'm used to IntelliJ but am using VS Code currently)

## How to Run

Install the dependencies with 

`$ npm install`

Use the `package.json` script `$ npm run vend` to start the user input loop
